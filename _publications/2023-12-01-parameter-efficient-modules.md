Composing Parameter-Efficient Modules with Arithmetic Operations
========================================================================================

This paper explores composing parameter-efficient modules using arithmetic operations for model optimization. The method enables efficient adaptation of pre-trained models with minimal parameter updates.

### Key Contributions

- Proposed a novel approach for composing parameter-efficient modules
- Used arithmetic operations to combine model components efficiently
- Evaluated the method on multiple downstream tasks

### Authors

Jinghan Zhang, Shiqi Chen, Junteng Liu, Junxian He
